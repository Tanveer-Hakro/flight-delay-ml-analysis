# Dataset

This project uses the **Flight Delay Dataset (2018–2022)** hosted on Kaggle. The executed analysis uses the file `Combined_Flights_2022.csv`.

Dataset page: https://www.kaggle.com/datasets/robikscube/flight-delay-dataset-20182022/data

The raw dataset is intentionally not included in this repository because of its size. Download the dataset from Kaggle and update `DATA_PATH` in the notebook if you are running locally.
